## The license of your contribution

This repository is free software under the GNU General Public License,
version 3 or (at your option) any later version. See [`COPYING`](COPYING)
for the full text. Your contribution carries the same license.

Braiins Systems s.r.o. reserves the right to license this program, or
any part thereof, under separate terms. This reservation covers every
contribution after it is merged. Braiins uses it to ship this code inside
proprietary products.

If you cannot agree to this position, do not submit the contribution.
Ask the question in the merge request thread first.

## The license header in a new file

Every new first-party source carries a license header with two parts.
The first part is the GPL-3.0-or-later grant. The second part is the
reservation above, and it is required. Copy the header from another file
in the same language.

The `license-headers` check gates this. A file that is missing either
part fails the check.

Third-party material keeps its own license. The tree already carries
some, and [`README.md`](README.md) lists it.

## Questions

Ask a licensing question in the merge request thread. This file states
the position of the project. It is not a signed agreement.
